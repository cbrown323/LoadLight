# Path discipline — LoadLight

LoadLight is a **Vite + React + JSX** app. Application code lives under **`src/`** (e.g. `src/components/*.jsx`, `src/store/useStore.js`, `src/lib/*.js`).

## Before suggesting edits or `@`-mentions

1. **Verify the path exists** in the repo (search or list `src/`) before naming it in a plan or task capsule.
2. **Do not assume** a Next.js `app/` tree, a top-level `lib/media/` TypeScript package, or `hooks/*.ts` unless those paths actually exist here.
3. **Do not introduce** `.ts` / `.tsx` files unless the user explicitly requests a TypeScript migration.
4. If a **new** file is required, name it with a clear **`NEW:`** prefix in the plan and place it under `src/` following existing patterns (prefer extending `src/lib/` for shared logic).

Workflow and agent rules live in **`awf/`** and root **`AGENTS.md`** — keep documentation paths consistent (`awf/AI_PROJECT_STATE.md`, `awf/DEV_LOG.md`).
